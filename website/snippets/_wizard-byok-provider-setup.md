Each provider asks for different details. Fill in the fields shown for your provider &mdash; the app explains each one as you go. Have these ready first:

<SimpleTable>

| Provider | Before you start |
|---|---|
| Amazon Bedrock | An Amazon Bedrock API key, with access to the Bedrock models you plan to use |
| Anthropic | An Anthropic API key. Enterprise and subscription licenses (such as Claude Enterprise) aren't supported per Anthropic's [terms of service](https://www.anthropic.com/legal/consumer-terms) |
| Azure OpenAI | An Azure API key for Azure AI Foundry or Azure OpenAI |
| Databricks | A Databricks personal access token (PAT) and deployed [serving endpoints](https://docs.databricks.com/en/machine-learning/model-serving/index.html) your token can query. For default endpoint names, refer to [Databricks Unity AI Gateway](/docs/dbt-ai/wizard-byok#databricks-unity-ai-gateway) |
| Google Gemini | A Google Gemini API key |
| OpenAI | An OpenAI API key |
| OpenAI subscription | A personal ChatGPT subscription. No API key needed |
| Snowflake Cortex (preview) | An API token or [Programmatic Access Token (PAT)](https://docs.snowflake.com/en/user-guide/programmatic-access-tokens#label-pat-generate), and privileges for [Cortex LLM functions](https://docs.snowflake.com/en/user-guide/snowflake-cortex/overview) |

</SimpleTable>
