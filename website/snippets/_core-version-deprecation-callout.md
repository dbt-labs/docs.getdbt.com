:::warning dbt Core v1.3 – v1.7 will be deprecated on <Constant name="legacy_deprecation_date" />
dbt Core versions v1.3-v1.7 have reached [end of life](/docs/dbt-versions#end-of-life-versions) and will be deprecated on <Constant name="legacy_deprecation_date" />. After that date, these versions are no longer maintained by dbt Labs and will be removed from <Constant name="dbt_platform" />.

Upgrade your environments to a [supported dbt version](/docs/dbt-versions) or a [release track](/docs/dbt-versions/dbt-release-tracks) before then to keep receiving updates and support. For more information, check out the [Migrate off legacy dbt versions](/guides/migrate-off-legacy-dbt-versions?step=1) guide.
:::
