:::note Authorizing additional access

When you register in the dbt VS Code extension, you might be prompted to authorize more access than you granted when signing in through the CLI (or the other way around). This is expected &mdash; some extension features need broader access than your initial sign-in. You can authorize the request with the same <Constant name="dbt_platform" /> account you already use, so a single account covers both the CLI and the dbt VS Code extension.

For more details on when re-authorization is triggered, refer to [Session expiry and re-authorization](/docs/sign-in-dbt-extension#session-expiry-and-re-authorization).

:::
