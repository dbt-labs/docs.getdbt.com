:::info dbt platform CLI support coming soon
The <Constant name="wizard" /> CLI doesn't yet work with the dbt platform CLI (formerly the dbt Cloud CLI). If your local `dbt` resolves to the dbt platform CLI, <Constant name="wizard" /> commands that compile your project may fail. Support for the dbt platform CLI is coming soon.

In the meantime, run the <Constant name="wizard" /> CLI in a project that uses <Constant name="fusion" /> or <Constant name="core" />.
:::
