:::info <Constant name="platform_cli" /> support coming soon
The <Constant name="wizard" /> CLI doesn't yet work with the <Constant name="platform_cli" /> (formerly the dbt Cloud CLI). If your local `dbt` resolves to the <Constant name="platform_cli" />, <Constant name="wizard" /> commands that compile your project may fail. Support for the <Constant name="platform_cli" /> is coming soon.

In the meantime, run the <Constant name="wizard" /> CLI in a project that uses <Constant name="fusion" /> or <Constant name="core" />.
:::
