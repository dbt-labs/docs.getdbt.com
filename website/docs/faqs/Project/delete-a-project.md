To delete a project in <Constant name="dbt" />, you must be the account owner or have admin privileges. 

1. From <Constant name="dbt" />, click on your account name in the left side menu and select **Account settings**.

<Lightbox src="/img/docs/dbt-platform/account-settings-menu.png" width="85%" title="Open Account settings from the account menu in the left sidebar" />

2. In **Account Settings**, select **Projects**. Click the project you want to delete from the **Projects** page.
3. Click **Edit** in the upper right corner of **Project details**. A **Delete** option appears.
4. Click **Delete**. Confirm the action to immediately delete the user without additional password prompts. The project is deleted immediately after confirmation. Once a project is deleted, this action cannot be undone. 

<Lightbox src="/img/docs/dbt-platform/delete_projects_from_dbt_cloud.png" width="85%" title="Delete projects" />
