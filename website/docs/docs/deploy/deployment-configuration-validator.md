## Feature requests

Need a **region**, **PrivateLink / PSC** variant, or **auth** pattern that is not covered yet?

- Use **[GitHub Discussions](https://github.com/dbt-labs/dbt_architecture_validator/discussions)** (or your team’s **Linear** project, when configured) to file a request. Include **SFDC opportunity**, **account**, **estimated ARR**, and **target GA** so Product can prioritize and dedupe.
- The draft **[platform capabilities catalog](/docs/deploy/deployment-platform-capabilities-catalog)** tracks lifecycle and connectivity posture. Source: **[dbt-cloud-platform-validator-metadata](https://github.com/dbt-labs/dbt-cloud-platform-validator-metadata)** (`platform_capabilities.yml`).
