The following steps walk you through the setup of a Teradata VantageCloud AWS PrivateLink endpoint in a <Constant name="dbt" /> multi-tenant environment.

<CloudProviders type='Teradata VantageCloud' />

## Configure AWS PrivateLink

1. Obtain the VPC endpoint service name for your Teradata PrivateLink Service and the AWS region of your Teradata environment from your Teradata account team or Teradata Support. The service name is generated by AWS and looks similar to:

   ```
   com.amazonaws.vpce.us-east-1.vpce-svc-0abc123def456ghi7
   ```

   :::note dbt AWS account
   If granting access to your Teradata endpoint service requires the <Constant name="dbt" /> AWS account ID, use **AWS account ID**: `346425330055` &mdash; _Note: This account ID only applies to AWS <Constant name="dbt" /> multi-tenant environments. For AWS Virtual Private/Single-Tenant account IDs, contact [dbt Support](mailto:support@getdbt.com)._
   :::

2. Add the required information to the following template and submit your AWS PrivateLink request to [dbt Support](mailto:support@getdbt.com):

   <Expandable alt_header="Support request email template" is_open={true}>

   ```text
   Subject: New AWS Multi-Tenant PrivateLink Request

   - Type: Teradata
   - Display name:
   - VPC Endpoint Service Name:
   - Port: 1025 (change if not default)
   - Teradata AWS Region (for example, us-east-1, eu-west-2):
   - dbt AWS multi-tenant environment (US, EMEA, AU, JP):
   ```

   </Expandable>

   <PrivateLinkSLA />

3. Once dbt Support confirms the endpoint has been provisioned and the connection has been tested, they will reply with the hostname to use when configuring your project.

## Create connection in dbt

Once you've completed the setup with dbt Support, you can configure a private endpoint in <Constant name="dbt" />:

1. Navigate to **Settings** → **Create new project** → select **Teradata**.
2. In the **Host** field, enter the hostname provided by dbt Support.
3. Configure the remaining [Teradata connection details](/docs/platform/connect-data-platform/connect-teradata).
4. Test your connection and save it.
