### Example query

<!-- NEED  UPDATE THIS EXAMPLE -->
You can use the `environmentId` and the model's `uniqueId` to return the model and its execution time for the last 20 times it was run, regardless of which job ran it.

```graphql
query ($environmentId: BigInt!, $first: Int!, $filter: FileFilter) {
  environment(id: $environmentId) {
    applied {
      files(
        filter: $filter, 
        first: $first
      ) {
        edges {
          node {
            description
            name
            filePath
            projectId
            fileType
            tags
            uniqueId
            resourceType
          }
        }
      }
    }
  }
}
```
