### Example query

<!-- NEED  UPDATE THIS EXAMPLE -->
You can use the `environmentId`, `first` and filter on the marts directory to return results for the first 100 files and file information in that directory:

```graphql
query ($environmentId: BigInt!) {
  environment(id: $environmentId) {
    applied {
      files(
        filter: {
          path: "models/marts"
        }, 
        first: 100
      ) {
        edges {
          node {
            description
            name
            filePath
            projectId
            fileType
            tags
            uniqueId
            resourceType
          }
        }
      }
    }
  }
}
```
