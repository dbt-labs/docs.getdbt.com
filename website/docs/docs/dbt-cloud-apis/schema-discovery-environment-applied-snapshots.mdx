Snapshots represent point-in-time copies of your data, allowing you to track historical changes. The Environment API provides comprehensive access to snapshot metadata, configurations, and relationships.. 

The [Example query](#example-query) illustrates a few fields you can query with the `snapshots` object. Refer to [Fields](#fields) to view the entire schema, which provides all possible fields you can query.

### Example query

<!-- NEED  UPDATE THIS EXAMPLE -->
You can use the `environmentId` and the model's `uniqueId` to return the model and its execution time for the last 20 times it was run, regardless of which job ran it.

```graphql
query {
  environment(id: 834) {
    applied {
      models (first: 100) {
        edges {
          node {
            name
            description
            access
            accountId
            catalog {
              owner
            }
            config
            environmentId
            tests {
              name
              description
            }
          }
        }
      }
    }
  }
}
```
