[Tags](/docs/reference/resource-configs/tags) provide a mechanism to categorize and group resources within a dbt project, enabling selective execution and management of these resources. You can query tags through the Discovery API.

The [Example query](#example-query) illustrates a few fields you can query with the `tags` object. Refer to [Fields](#fields) to view the entire schema, which provides all possible fields you can query.

### Example query

<!-- NEED  UPDATE THIS EXAMPLE -->
You can use the `environmentId` and the model's `uniqueId` to return the model and its execution time for the last 20 times it was run, regardless of which job ran it.

```graphql
query {
  environment(id: 834) {
    applied {
      models (first: 100) {
        edges {
          node {
            name
            description
            access
            accountId
            catalog {
              owner
            }
            config
            environmentId
            tests {
              name
              description
            }
          }
        }
      }
    }
  }
}
```
