The resources object allows you to paginate across all resources in your environment.

The [Example query](#example-query) illustrates a few fields you can query with the `resources` object. Refer to [Fields](#fields) to view the entire schema, which provides all possible fields you can query.

### Example query

<!-- NEED  UPDATE THIS EXAMPLE DESCRIPTION -->
You can use the `environmentId`, filtering on the `Model` type, and the first 100 results, to return information about the first 100 models in the given environment:

```graphql
query {
  environment(id: 834) {
    applied {
      resources(
        filter: {
          types: [
            Model
          ]
        }, 
        first: 100
      ) {
        edges {
          node {
            accountId
            description
            environmentId
            filePath
            meta
            name
            projectId
            resourceType
            uniqueId
            tags
          }
        }
      }
    }
  }
}
```
