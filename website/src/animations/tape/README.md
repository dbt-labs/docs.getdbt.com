# VHS Tape Animations

Terminal GIF animations using [VHS](https://github.com/charmbracelet/vhs).

## Install

```bash
brew install vhs
```

## Usage

```bash
cd blog/2026-02-03-dbt-agent-skills
vhs without_skill.tape
vhs with_skill.tape
```

Edit `.sh` scripts to change content/timing, then re-run VHS.
